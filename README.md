# Play & Watch

Приватная общая коллекция фильмов, сериалов и игр для двух друзей. Интерфейс на React + TypeScript, API на Python + FastAPI, база SQLite. Оба пользователя добавляют записи и заметки через раздел **«Управление»**; администратор также редактирует и удаляет записи и управляет аккаунтами.

## Требования

- Python 3.12+
- Node.js 20+
- npm 10+

## Установка

В PowerShell из корня проекта:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `backend/.env` и **обязательно замените** `ADMIN_PASSWORD` и `FRIEND_PASSWORD` на разные пароли длиной не менее 12 символов. При первом запуске сервер создаст оба аккаунта. `.env` и база данных исключены из Git.

Установите интерфейс:

```powershell
cd ..\frontend
npm install
```

## Метаданные и ключи

Сайт полностью работает без ключей: в «Управлении» выберите тип и заполните поля вручную. При недоступности внешнего API или неизвестной ссылке форма остаётся доступной. Для автоматического поиска добавьте в `backend/.env`:

- `TMDB_API_KEY`: зарегистрируйтесь на [TMDB](https://www.themoviedb.org/signup), запросите API key в настройках аккаунта. [Справка API](https://developer.themoviedb.org/docs/getting-started). Используется для фильмов и сериалов; описания при просмотре карточки запрашиваются на выбранном языке.
- `RAWG_API_KEY`: зарегистрируйтесь и получите ключ на [RAWG Developers](https://rawg.io/apidocs). Используется для игр. Описание игр отдаётся на языке, доступном у RAWG; при необходимости его можно поправить вручную через администратора.

Ключи хранятся **только на сервере**. Для личного некоммерческого использования TMDB и RAWG требуют атрибуции. В интерфейсе есть ссылки на источники в карточках и футере, официальный логотип и требуемый текст TMDB. Перед коммерческим использованием проверьте действующие [условия TMDB](https://developer.themoviedb.org/docs/faq) и [условия RAWG](https://rawg.io/apidocs).

Поддерживаются ссылки вида `themoviedb.org/movie/ID`, `themoviedb.org/tv/ID` и `rawg.io/games/slug`. Любая другая HTTPS/HTTP-ссылка открывает ручную форму. Ссылки других схем отвергаются.

## Данные и безопасность

- Пароли хешируются с индивидуальной солью через `scrypt`; пароли в базе не хранятся.
- Сессия передаётся через HttpOnly cookie, в базе хранится только SHA-256 токена. Локальный сервер использует `SameSite=Lax` и проверку специального заголовка для изменяющих запросов.
- Для публичного размещения потребуется HTTPS и `Secure` cookie, настройка домена/CORS и отдельная оценка безопасности. Этот проект настроен для локального использования.
- Повтор одного и того же внешнего ID отклоняется. Ручные записи сравниваются по типу, нормализованному названию и году; если год не указан, совпадающее название того же типа также считается дубликатом.
- Администратор может сбросить пароль пользователя через «Настройки → Пользователи». Исходные пароли из `.env` используются только для первоначального создания аккаунтов.

## Проверки

```powershell
cd backend
.\.venv\Scripts\python -m pytest -q
cd ..\frontend
npm run build
```

Вручную проверьте вход обоих аккаунтов, добавление из поиска TMDB и RAWG с вашими ключами, неизвестную ссылку и ручное добавление, смену статуса и историю, заметки, фильтры и случайный выбор, переключение RU/EN, права друга и действия администратора. Проверьте вид на узком экране и заглушку отсутствующей/битой картинки.
